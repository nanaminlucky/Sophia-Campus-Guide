# Sophia Campus Guide　🦅

上智大学のキャンパス案内、および周辺の飲食店を紹介するアプリケーションです。
大学のPython入門授業の課題の一環として作成しました。

👉 **[Sophia Campus Guide を体験する](https://sophia-campus-guide.onrender.com)**

## 概要と特徴
- **全学内施設の網羅**: 上智大学のすべての建物をカバーし、写真と一緒に確認できるようにしています。
- **周辺グルメ情報の掲載**: 大学周辺にある飲食店（NO.4、町田商店、デニーズなど）の情報をまとめています。
- **シンプルな操作性**: 誰でも使いやすいよう、文字やボタンを大きめに配置し、絵文字を使って直感的に操作できるように工夫しています。

## こだわった点
- **Google Map へすぐ飛べる導線**: 行きたいお店の場所をその場で確認できるので、地図アプリを開いて再検索する手間がなく、初めてのお店でも迷わず行きやすくなります。
- **写真と説明をセットで表示**: 建物や店舗を画像だけで終わらせず、説明文も同時に見られるようにして、初見でもイメージしやすくしました。
- **現役上智生目線の情報**: 授業、ゼミ、待ち合わせ、ランチなど、実際の学生生活で役立つ視点のコメントを入れています。
- **目的別に探しやすい構成**: キャンパスマップと四ツ谷グルメを分けて、知りたい情報にすぐアクセスできるようにしました。
- **見やすさを意識したUI**: ラジオボタンや大きめの文字を使い、スマホやブラウザでも迷わず操作しやすい画面にしています。

## 🛠️ 自分のPC（ローカル環境）で動かす方法

自分のパソコンのターミナルを使ってアプリを起動する手順です。

### 1. 準備（ライブラリのインストール）
ターミナル（またはコマンドプロンプト）を開き、このプロジェクトのフォルダに移動した状態で、必要なライブラリをインストールします。
```bash
pip install -r requirements.txt
```

### 2. アプリの起動
以下のコマンドを入力して実行します。
```bash
python app.py
```

### 3. ブラウザで確認
起動すると、ターミナルに以下のような文字が表示されます。
`Running on local URL:  http://127.0.0.1:7860`

この **`http://127.0.0.1:7860`** をコピーしてブラウザ（Chromeなど）のURLバーに貼り付けてエンターキーを押すと、自分のPC上でアプリが動き出します。
（※アプリを終了したいときは、ターミナルで `Ctrl + C` を押します）
